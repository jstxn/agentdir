# AgentDir v0.7.3

AgentDir v0.7.3 adds an adoption-time Git ignore choice for the repo-local
`.agentdir` store.

## Changes

- `agentdir adopt` and `agentdir setup` now support
  `--gitignore ask|project|user|none`.
- Interactive runs ask whether `.agentdir/` should be ignored at the project or
  user Git ignore level.
- Non-interactive and JSON runs skip the prompt unless a target is selected
  explicitly.
- Repeated adoption is idempotent and does not duplicate `.agentdir/` ignore
  entries.

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.7.3' | bash
```

Rollback to v0.7.2 is one command:

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/rollback.sh?ref=v0.7.3' | bash
```
