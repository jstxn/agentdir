# AgentDir v0.2.0

AgentDir v0.2.0 moves the project from explicit manual recording toward an agent-first workflow.

## What Changed

- `agentdir setup` initializes a project store, installs managed Git hook shims, and installs Codex guidance
- `agentdir session start/current/end` manages the active coding-agent session
- `agentdir run -- <command>` captures tool calls and tool results while streaming command output
- Stored command output is size-bounded and redacts common secret-like patterns
- `agentdir hooks install/status/uninstall/record` manages Git hook recording without destroying existing hooks
- `agentdir skills install codex --target user|project|store` generates agent guidance
- `agentdir summarize` and `agentdir evidence` provide deterministic local review output

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.2.0' | bash
```

## Quick Agent-First Smoke

```bash
agentdir setup --codex-skill store
agentdir session start --id release-smoke --title "release smoke"
agentdir run -- python3 -c "print('release smoke')"
agentdir summarize
agentdir evidence
agentdir doctor
```
