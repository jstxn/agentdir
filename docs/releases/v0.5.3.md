# AgentDir v0.5.3

AgentDir v0.5.3 fixes a derived-index false positive in the v0.5.2 secret
doctor.

## What Changed

- Keeps `doctor` strict for raw envelope bodies and message-level index bodies
- Stops treating tokenized memory passage chunks as independent secret-bearing
  sources, because chunking can join harmless source tokens into false
  key-value-looking patterns
- Preserves the `agentdir secrets scan` and `agentdir secrets redact --apply`
  cleanup flow for real persisted body findings

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.5.3' | bash
```

## Rollback

Rollback to v0.5.2 is one command:

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/rollback.sh?ref=v0.5.3' | bash
```
