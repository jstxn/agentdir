# AgentDir v0.5.2

AgentDir v0.5.2 keeps the v0.5.1 secret-handling hardening and fixes the
upgrade verifier when AgentDir is invoked by absolute path from an isolated
install prefix.

## What Changed

- Preserves v0.5.1 body redaction, `doctor` failures for persisted secret-like
  bodies, and `agentdir secrets scan` / `agentdir secrets redact --apply`
- Fixes `agentdir --upgrade` to prefer the currently invoked executable before
  falling back to the first `agentdir` on `PATH`
- Keeps upgrade verification honest by failing when the post-install version
  does not match the requested release

## Upgrade

```bash
agentdir --upgrade
```

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.5.2' | bash
```

## Rollback

Rollback to v0.5.1 is one command:

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/rollback.sh?ref=v0.5.2' | bash
```
