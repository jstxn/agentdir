# AgentDir v0.6.0

AgentDir v0.6.0 makes agent compliance visible without changing the
human-owned workflow. Engineers still do normal coding work; agents operate
AgentDir in the background, and AgentDir can now report whether the session left
useful evidence.

## What Changed

- Adds `agentdir audit session` for advisory session compliance checks
- Adds `agentdir audit claims` for deterministic final-claim-to-evidence checks
- Adds `Session Audit` and optional `Claim Support` sections to final reports
- Adds generic managed `AGENTS.md` guidance alongside the Codex skill
- Extends `adopt` and `setup` with generic guidance installation
- Fixes the dogfood fallback path to require Python 3.11 or newer and respect
  `AGENTDIR_PYTHON`
- Makes `replay` recover when the derived SQLite index is missing

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.6.0' | bash
```
