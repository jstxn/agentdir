# AgentDir v0.4.0

AgentDir v0.4.0 adds explicit retention commands and quieter default guidance for coding agents.

## What Changed

- Adds `agentdir archive` for moving inactive session mailboxes out of active query and memory results
- Adds `agentdir prune` for deleting selected archived sessions
- Keeps both retention commands dry-run by default until `--apply` is passed
- Protects the current active session from archive and prune operations
- Requires `--include-live-sessions` before `prune` will consider live session mailboxes
- Adds `archives/sessions/` to the store layout
- Updates the generated Codex skill to leave routine exploration commands unwrapped
- Documents the evidence-capture boundary so `agentdir run` is reserved for tests, builds, repros, release checks, and claim-supporting diagnostics
- Improves the installer fallback by selecting Python 3.11 or newer before creating the virtual environment

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
```
