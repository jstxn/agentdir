# AgentDir v0.5.0

AgentDir v0.5.0 promotes the agent workbench, local memory plane, and rollback
story into the release surface.

## What Changed

- Adds the `agentdir work` flow for agent-owned start, status, final report, and
  finish behavior
- Adds auditable context packs with consume, cite, and audit events
- Adds explicit cross-repo memory through registered roots and root groups
- Adds optional warm indexing with `agentdir memory daemon`
- Adds optional semantic and team backend configuration surfaces
- Adds richer status and doctor output through the core CLI dependencies
- Moves default user and machine roots to platform application-data locations
  while preserving legacy root fallback behavior
- Updates the generated Codex skill so agents use the workbench flow and keep
  routine exploration commands unwrapped
- Allows AgentDir-managed Codex skill installs to update in place while keeping
  a backup of the previous generated skill
- Adds `rollback-agentdir.sh` so a release can be rolled back without relying on
  the installed `agentdir` binary
- Adds `agentdir --version` for quick install and rollback verification

## Rollback

Rollback to v0.4.0 is one command:

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/rollback.sh?ref=v0.5.0' | bash
```

The rollback script fetches the installer from the target release tag and
reinstalls that wheel. It does not need the current `agentdir` CLI to work.

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.5.0' | bash
```
