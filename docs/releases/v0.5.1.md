# AgentDir v0.5.1

AgentDir v0.5.1 hardens secret handling and adds a single-command upgrade path.

## What Changed

- Redacts common secret-like patterns from emitted envelope bodies before persistence
- Keeps `agentdir run` stored output redaction in place while extending redaction to manual emits and actor messages
- Makes `doctor` fail when persisted envelope bodies still contain secret-like text
- Adds `agentdir secrets scan` for path-only secret triage without printing body text
- Adds `agentdir secrets redact --apply` to rewrite affected bodies and rebuild the derived SQLite index
- Adds `agentdir --upgrade` to reinstall the latest release, re-adopt the current repo, refresh hooks and skill integration, and run doctor

## Upgrade

```bash
agentdir --upgrade
```

Useful variants:

```bash
agentdir --upgrade --upgrade-install-skill none
agentdir --upgrade --upgrade-no-adopt
agentdir --upgrade --upgrade-dry-run
```

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.5.1' | bash
```

## Rollback

Rollback to v0.5.0 is one command:

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/rollback.sh?ref=v0.5.1' | bash
```
