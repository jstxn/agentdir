# AgentDir v0.3.3

AgentDir v0.3.3 hardens the agent-owned workflow for overlapping agent actions.

## What Changed

- Serializes SQLite index rebuilds with an AgentDir lock file
- Uses unique temporary index paths for rebuilds before atomic replacement
- Adds regression coverage for concurrent `summarize`, `evidence`, and `memory search`
- Keeps the hands-off `agentdir session ensure` workflow from v0.3.2

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.3.3' | bash
```
