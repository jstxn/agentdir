# AgentDir v0.1.1

AgentDir v0.1.1 improves the engineer install and storage workflow.

## What Changed

- Single-command private GitHub install through `gh api ... | bash`
- Default project-scoped AgentDir root at `<repo>/.agentdir`
- Optional `--root` across CLI commands instead of mandatory `--root`
- `--scope project`, `--scope user`, `--scope global`, and `--scope machine`
- `agentdir root` command for scripting and debugging
- Agentic coding docs now use project-scoped defaults

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.1.1 | bash
```

## Quick Project Store Smoke

```bash
agentdir init
session="release-smoke"
printf 'release smoke\n' > /tmp/agentdir-smoke.txt
agentdir emit --session "$session" --type agent.message --body /tmp/agentdir-smoke.txt
agentdir index rebuild
agentdir replay --session "$session"
agentdir doctor
```
