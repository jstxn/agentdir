# AgentDir v0.3.1

AgentDir v0.3.1 keeps the agent memory release current with the new user-facing project introduction.

## What Changed

- Adds a minimal README visual that explains AgentDir as a saved trail, searchable memory, and proof layer for engineers
- Updates install docs and installer defaults to point at the current patch release
- Includes README image assets in the source distribution manifest
- Keeps the GitHub Release assets aligned with the README and package metadata

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.3.1' | bash
```
