# AgentDir v0.10.0

AgentDir v0.10.0 adds optional Jev context filtering, so coding agents can see
fewer irrelevant sources in the briefing that `work start` prints. It is off by
default. Context selection stays fully local unless you turn it on for a store.

## Added

- `agentdir memory reranker configure jev|none` turns Jev filtering on or off
  for each store. Once it is enabled, `work start` and `context build` send the
  task and up to 20 locally retrieved candidate passages to the pinned
  `jev-1.13.0` model. Candidates scoring below 0.7 are dropped before source
  diversification.
- Context JSON and persisted manifests record `reranking` metadata: status,
  model, rubric version, cutoff, candidate identities, sanitized-text hashes,
  scores, usage, and latency. Each surviving source keeps its original
  `memory_score` alongside a new `rerank_score`.
- `scripts/eval_jev.py` and its synthetic fixture reproduce the evaluation
  behind this feature. See
  [the evaluation](../investigations/2026-09-21-jev-evaluation.md).

## Safety and fallback

- The API key is read only from `TYPESAFE_API_KEY` or `JEV_API_KEY` in the
  process environment. It is never written to configuration, and `.env` files
  are not loaded automatically.
- Common secret patterns and the configured key are redacted before sending.
  Redaction does not anonymize proprietary material. Review TypeSafe's data
  handling before opting in.
- Missing credentials, request failures, malformed responses, and the
  three-second deadline all fall back to local selection and report a reason.
  There are no retries.
- Federated and group context always uses local selection. Reviewing a saved
  pack or rebuilding the index never calls Jev.
- Jev scores are advisory. They cannot verify evidence or mark a source as
  read, used, or cited, and the agent's context review is still required.

## Fixed

- Concurrent writers of the same file, such as the memory daemon and the
  command that starts it, no longer collide on a shared temp file. This caused
  an intermittent `FileNotFoundError` when starting the daemon.
- Jev tests stub only Jev's subprocess calls, so git lookups made during a test
  no longer depend on an earlier test having cached them.

## Compatibility

- Nothing changes for stores that do not opt in. No new Python dependency is
  required.
- The public installer defaults to v0.10.0. The bundled rollback script
  defaults to v0.9.0.

## Upgrade

```bash
agentdir update
```
