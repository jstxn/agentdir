# AgentDir v0.3.0

AgentDir v0.3.0 turns the local flight recorder into a built-in agent memory substrate.

## What Changed

- `agentdir index rebuild` now creates message memory and derived session-summary memory
- `agentdir memory search <query>` retrieves similar prior work out of the box
- `agentdir memory explain <query>` reports score, source, overlap terms, and excerpt
- `agentdir context build <task>` creates an agent-ready context pack from memory, evidence, and recent summaries
- `agentdir query --semantic <query>` supports vector-ranked search while honoring filters
- The generated Codex skill now tells agents to build context before non-trivial work

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.3.0' | bash
```

## Quick Agent Memory Smoke

```bash
agentdir setup --codex-skill store
agentdir session start --id release-smoke --title "release smoke"
agentdir run -- python3 -c "print('release smoke')"
agentdir memory search "release smoke"
agentdir memory explain "release smoke"
agentdir context build "release smoke"
agentdir summarize
agentdir evidence
agentdir doctor
```
