# AgentDir v0.9.0

AgentDir v0.9.0 makes retrieved context easier for coding agents to read,
evaluate, and use before they change a repository. It also tightens session
integrity, evidence classification, and final handoffs.

## Added

- `agentdir work context --expand <number>` returns bounded, verified source
  content and records metadata-only delivery receipts.
- Normal `work start` uses fused semantic and lexical retrieval when FastEmbed
  is configured. `memory explain` reports the actual retrieval mode and scores.
- Context audits expose retrieved, presented, expanded, used, dismissed, and
  pending counts without treating delivery as proof of model attention.
- `agentdir work finish --json --brief` returns a bounded handoff for agents
  while the full forensic report remains available.

## Improved

- Briefings prefer decisions, evidence, and relevant summaries over lifecycle
  events, duplicate reports, and weak backfill.
- Context review supports one terminal decision with multiple `--use` values.
- Evidence families are derived from structured command identity instead of
  paths or command output, including common Python and CI wrapper forms.
- Historical failures remain inspectable while later passing evidence resolves
  the active failure state.

## Fixed

- Session and context lifecycle locks prevent concurrent start, finish, and
  context-pack operations from being attributed to the wrong session.
- Git-native checkout identities keep parallel sessions separate across
  same-named worktrees and shared user stores, including moved worktrees.
- Context manifests, decisions, expansion receipts, archived records, and
  federated sources fail safely on malformed identity or integrity metadata.
- Git provenance stays attached to the owning checkout when work finishes from
  another directory or a same-named repository.
- ONNX Runtime telemetry and model caches no longer dirty the user's checkout.

## Compatibility

- Existing context-pack protocols and legacy consume/cite events remain
  readable. Source expansion is optional and does not gate `work finish`.
- The public installer defaults to v0.9.0. The bundled rollback script defaults
  to v0.8.0.

## Upgrade

```bash
agentdir update
```
