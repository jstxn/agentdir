# AgentDir v0.7.2

AgentDir v0.7.2 removes one more setup-noise issue found while upgrading the
AgentDir repository itself after v0.7.1.

## Fixes

- Re-running project integration install is now byte-stable for managed-only
  guidance files.
- Managed guidance updates no longer insert leading blank lines before
  `AGENTS.md`, `CLAUDE.md`, or Copilot instruction blocks.

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.7.2' | bash
```

Rollback to v0.7.1 is one command:

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/rollback.sh?ref=v0.7.2' | bash
```
