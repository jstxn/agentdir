# AgentDir v0.7.1

AgentDir v0.7.1 smooths the first real dogfood adoption experience for the
ambient integration release.

## What Changed

- Git-hook-only recordings now create and close a background session instead of
  leaving an active session behind
- Git hook events still attach to an existing active work session when one is
  present
- `integrations doctor` now reports an effective Codex install when the Codex
  skill is installed at the user or store target, instead of showing a confusing
  project-level miss

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.7.1' | bash
```

## Rollback

Rollback to v0.7.0 is one command:

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/rollback.sh?ref=v0.7.1' | bash
```
