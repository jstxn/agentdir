# AgentDir v0.7.4

AgentDir v0.7.4 sharpens vector memory search quality and removes redundant
index rebuilds from the status, report, and audit flows.

## Changes

- Raise the hashed feature vector dimension from 256 to 1024. Vectors are stored
  sparsely, so storage cost is unchanged while hash collisions between unrelated
  terms drop substantially.
- Preserve the semantic embedding cache across index rebuilds. Rebuilds start
  from an empty temporary database, which previously discarded every cached
  `fastembed` vector and forced a full corpus re-embed on the next semantic
  query. Valid rows are now carried forward and rows whose document text changed
  or disappeared are pruned via the content-hash join.
- Reuse `fastembed` `TextEmbedding` instances across calls instead of reloading
  the model on every embed.
- Apply the session-summary ranking penalty exactly once. Hybrid, semantic, and
  document modes now share a single `SESSION_SUMMARY_PENALTY` multiplier and sort
  on the resulting score, replacing the inconsistent per-mode penalties.
- Rebuild the search index once per report flow. `status`, `report final`, and
  the session/claims audits previously rebuilt the SQLite index several times
  while assembling a single report; the rebuild now happens once up front and the
  result is reused.

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.7.4' | bash
```

Install the Pi package from npm or the release tag:

```bash
pi install npm:@jstxn/agentdir-pi@0.7.4
pi install git:github.com/jstxn/agentdir@v0.7.4
```

Rollback to v0.7.3 is one command:

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/rollback.sh?ref=v0.7.4' | bash
```
