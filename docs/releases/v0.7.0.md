# AgentDir v0.7.0

AgentDir v0.7.0 sharpens the invisible workflow stance: engineers install and
adopt once, then agents operate AgentDir during normal work and consume the
handoff data themselves.

## What Changed

- Adds an agent-first `agent_handoff` object to JSON final reports and
  `work finish --json`
- Adds evidence family classification plus `agentdir evidence --brief`,
  `--family`, `--failed`, and `--json` skim views
- Adds `agentdir timeline` for compact session event order
- Adds `agentdir adopt --dry-run`, `agentdir setup --dry-run`, and
  `agentdir unadopt` for explicit, reversible setup
- Adds broad ambient integrations for generic/Codex, Claude, Copilot, Cursor,
  and Windsurf guidance
- Changes adoption defaults toward project-level ambient guidance while keeping
  existing skill and generic guidance flags as compatibility aliases
- Updates docs around the raw-envelope source of truth, rebuildable SQLite
  index, what setup writes, and how to undo managed setup

gh api -H "Accept: application/vnd.github.raw" \
