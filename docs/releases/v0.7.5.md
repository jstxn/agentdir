# AgentDir v0.7.5

AgentDir v0.7.5 brings AgentDir to PyPI as `agentdir-cli`, simplifies installs
now that the repository is public, and finishes the single-rebuild work for
report flows.

## Changes

- Publish to PyPI as `agentdir-cli`. The plain `agentdir` name on PyPI is held
  by an unrelated project, so the distribution is `agentdir-cli` while the
  importable package and the CLI command remain `agentdir`. Releases upload to
  PyPI automatically through a trusted-publishing workflow.
- Install without authentication. The repository is public, so the installer
  and rollback scripts download release assets with anonymous `curl` first and
  fall back to authenticated GitHub CLI. The installer accepts both the new
  `agentdir_cli-*` wheel name and the legacy `agentdir-*` name so version pins
  and rollbacks to v0.7.4 or earlier keep working, and pipx installs replace an
  existing install under the old distribution name.
- Finish the single-rebuild behavior for report flows. The v0.7.4 notes
  described a single index rebuild per report flow, but part of that change
  missed the release: `status`, context-pack building, and the standalone
  session and claims audits still rebuilt the SQLite index several times per
  call. Each now rebuilds once and reuses the result, and `timeline_rows`
  accepts the same `rebuild` flag as the other readers.

## Install

From PyPI:

```bash
uv tool install agentdir-cli
# or
pipx install agentdir-cli
```

Or with the release installer:

```bash
curl -fsSL https://raw.githubusercontent.com/jstxn/agentdir/main/scripts/install.sh | bash
```

Install the Pi package from npm or the release tag:

```bash
pi install npm:@jstxn/agentdir-pi@0.7.5
pi install git:github.com/jstxn/agentdir@v0.7.5
```

Rollback to v0.7.4 is one command:

```bash
curl -fsSL https://raw.githubusercontent.com/jstxn/agentdir/main/scripts/rollback.sh | bash
```
