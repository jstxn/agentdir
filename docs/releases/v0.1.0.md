# AgentDir v0.1.0

AgentDir v0.1.0 is the first installable GitHub release.

## What Is Included

- `agentdir` Python CLI
- Maildir-like atomic event delivery through `tmp -> new`
- RFC 5322-style immutable envelopes for agent work records
- rebuildable SQLite index
- session query and replay
- actor inbox/outbox handoff
- content-addressed artifact storage
- `doctor` diagnostics for malformed envelopes, duplicate IDs, missing blobs, and secret-like bodies
- dogfood demo for replay after index deletion

## Install

For engineers with access to the private repo:

```bash
tmpdir="$(mktemp -d)"
gh release download v0.1.0 \
  --repo jstxn/agentdir \
  --pattern install-agentdir.sh \
  --dir "$tmpdir"
bash "$tmpdir/install-agentdir.sh"
```

## Quick Smoke

```bash
agentdir --help
root="$(mktemp -d)/agentdir-root"
printf 'release smoke\n' > /tmp/agentdir-smoke.txt
agentdir init "$root"
agentdir emit --root "$root" --session release-smoke --type agent.message --body /tmp/agentdir-smoke.txt
agentdir index rebuild --root "$root"
agentdir replay --root "$root" --session release-smoke
agentdir doctor --root "$root"
```

## Notes

This release is local-first and GitHub-only. It does not require a daemon, Dovecot, Redis, RabbitMQ, SQS, npm, or PyPI.
