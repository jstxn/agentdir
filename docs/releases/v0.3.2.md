# AgentDir v0.3.2

AgentDir v0.3.2 makes the daily workflow explicitly agent-owned.

## What Changed

- Adds `agentdir session ensure`, an idempotent command for agents to create or reuse the active session
- Updates the generated Codex skill so users are not asked to run AgentDir commands during normal coding work
- Reframes README and agentic coding docs around install-once, then let the coding agent record work in the background
- Keeps release smoke commands on the same hands-off session path agents should use

## Install

```bash
gh api -H "Accept: application/vnd.github.raw" \
  'repos/jstxn/agentdir/contents/scripts/install.sh?ref=v0.3.2' | bash
```
